# Changelog

## 1.2.0 - 2026-09-15

- Added evidence-based panel design section grounded in Consensus literature on team creativity, facilitation, psychological safety, and groupthink prevention.
- Added explicit `role:chair` facilitator with phase boundaries, norm setting, second-chance dissent, and anti-herding behaviors.
- Expanded panel protocol from three to five phases: packet/norms → independent divergent pass → mutual examination → convergent refinement → chair synthesis.
- Added research-backed failure modes: early chair verdict, buildup trap, herding, hidden-profile miss, performative devil's advocate, participation gamification.
- Added `reference.md` with chair checklist, phase map, Consensus queries, and bibliography.
- Updated README with v1.2.0 panel design summary.

## 1.1.0 - 2026-09-05

- Added `standard`, `panel`/`five-role`, and single-role review modes.
- Added isolated first-pass analysis for opposition, questioner, opportunity, outsider, and executor roles.
- Added mutual examination, chair synthesis, calibrated verdicts, stop conditions, and one-action execution guidance.
- Added an honest same-model sequential fallback when isolated subagents are unavailable.

## 1.0.0 - 2026-08-29

- Reworked the skill as a portable, field-agnostic research review guide.
- Removed project-specific examples and platform-specific installation language.
- Removed platform-specific agent metadata.
- Added explicit source provenance, evidence-scope, uncertainty, and tool-availability rules.
- Added the complete GNU Affero General Public License v3.0 or later text and standalone project documentation.
